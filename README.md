# Пульс — опросники и викторины в реальном времени

## Аккаунты, общий каталог и результаты тестов

Теперь каждый участник может войти, создавать личные опросы и публиковать выбранные
опросы в общем каталоге. По умолчанию новый опрос личный; его вопросы доступны только
автору. Опубликованный опрос можно запустить или скопировать в свою личную библиотеку.
Снятие с публикации сохраняет уже проведённые игры и созданные другими авторами копии.
Вход по прежнему паролю администратора сохранён. Участие в комнате по коду без
регистрации также остаётся доступным, но для сохранения игры в личном профиле следует
войти в аккаунт перед присоединением.

Для одинаковых аккаунтов с марафоном:

1. В GitDeck обновите панель до **1.5.0**, затем Пульс и марафон.
2. На карточке Пульса нажмите **«Подключить марафон»**, выберите его модуль и отдельный
   HTTPS-адрес Пульса, например `https://pulse.vano.sbena.net/`.
   Поддомен должен указывать на сервер; существующая wildcard-запись подходит.
   При `compose.https.yaml` у марафона панель добавляет маршрут в его Caddy,
   сохраняя основной адрес марафона и маршруты других сайтов.
3. Войдите в Пульс по прежнему паролю администратора → **Участники** →
   **Обновить список из марафона**. Повторный импорт обновляет существующие аккаунты,
   имена, роли и активность; совпадение имени не объединяет разные аккаунты.
4. Участники нажимают **«Войти через марафон чтения»** и подтверждают свой профиль.
   Работает существующий вход марафона, в том числе через Telegram.
   Пароли, Telegram ID и результаты чтения не передаются.

В **Ведомости тестов → Внести прошедший тест** администратор или модератор задаёт
название, дату и максимум баллов, затем вносит баллы участникам. Формула:
`процент = баллы / максимум × 100`, округление до двух знаков.
Например, при максимуме 1000: 750 → 75%, 650 → 65%, 0 → 0%.
Пустая ячейка означает «не внесено» и не считается нулём. Значения вне диапазона
0…максимум не сохраняются. Ведомость можно исправить, удалить с подтверждением
или выгрузить CSV для Excel. При конкурентном изменении нужно открыть свежую версию.
Участники видят только собственные оценки, команда — полную ведомость.

Для прежних игр откройте **История игр → Связать участников** и явно сопоставьте
старое игровое имя с аккаунтом. Это сохраняет идентификатор игрока, ответы и баллы.
Автоматического сопоставления по имени нет: оно может приписать чужой результат.

Подключение использует `PULSE_BRIDGE_SECRET` и адреса `MARATHON_URL` / `PULSE_URL`.
GitDeck создаёт секрет и Compose-наложения автоматически, без копирования баз.
Файлы `.env`, `compose.gitdeck-community.yaml` и существующие данные сохраняются
при обновлении кода. Секрет нельзя публиковать в репозитории. Старые SQLite-таблицы
дополняются новыми колонками без пересоздания результатов.

Проверки: `python tests/community.py`; с `COMMUNITY_UI=1` и установленным Playwright —
проверка реального браузера на ширинах 320, 390 и 1280 пикселей.

В одном репозитории `https://github.com/qboshenkiy/my_sites` находятся четыре приложения:
Пульс в корне, марафон чтения в `marathon/`, панель обновлений в `deploy-panel/`
и Chrono Logos в `chrono_logos/`. Они запускаются отдельно и сохраняют собственные данные.
Для Chrono Logos в GitDeck укажите этот репозиторий, ветку `main` и папку `chrono_logos`.
В Chrono Logos доступны импорт/экспорт JSON, готовый набор Бытия по 50 главам и выбор
состава игры без удаления карточек. Формат и работа с несколькими книгами описаны в
[chrono_logos/TIMELINE_JSON.md](chrono_logos/TIMELINE_JSON.md).

Проект для Laragon и Linux-сервера: PHP 8.1+ и SQLite (`pdo_sqlite`, `mbstring`). Composer, Node.js и MySQL не нужны.

## Запуск на Hetzner Cloud

Для уже установленного сайта используйте `dist/pulse-update.tar.gz` и [UPDATE.md](UPDATE.md): архив обновления сохраняет `.env`, данные и настройки доменов. Новые функции: изображения, категории с баллами, фиксированная награда всем правильным ответам, QR-вход, отдельный экран проектора и места игроков в рейтинге.

Готовые архивы: `dist/pulse-server.zip` и `dist/pulse-server.tar.gz`. Они не содержат рабочую базу и пароль администратора.

На сервере с Docker и Docker Compose распакуйте архив и запустите `bash start.sh`. Для домена и HTTPS: `bash start.sh quiz.example.com`. Подробные команды загрузки, запуска и резервного копирования — в [DEPLOY.md](DEPLOY.md).

Пересборка архивов после изменений: `python tools/package.py`.

Локальный Docker-просмотр в этом проекте: `http://localhost:8090/` (порт задан в локальном `.env` и не попадает в серверный архив).

## Запуск

1. Включите Apache в Laragon.
2. Откройте `http://localhost/my_project/`.
3. При первом запуске задайте пароль администратора (не менее 8 символов). Регистрации новых администраторов после этого нет.
4. Создайте опросник или отредактируйте один из трёх примеров. Запустите игру, дождитесь игроков и нажмите «Начать игру».

Для отдельного сервера из папки проекта:

```powershell
& 'C:/laragon/bin/php/php-8.3.33-Win32-vs16-x64/php.exe' -S 0.0.0.0:8080 router.php
```

## Подключение с телефона

Компьютер и телефоны должны быть в одной Wi-Fi сети. Узнайте IPv4 компьютера командой `ipconfig`. Например, при IP `192.168.1.10`:

- Apache: `http://192.168.1.10/my_project/#join`
- Отдельный сервер: `http://192.168.1.10:8080/#join`

Введите шестизначный код с экрана ведущего и имя. При необходимости разрешите Apache/PHP входящие подключения в брандмауэре Windows для частной сети. Телефон не сможет открыть `localhost` вашего компьютера. Открывайте панель ведущего через сетевой IP, чтобы копируемая ссылка сразу подходила участникам.

## Возможности

- Пароль администратора, сессии, защита от CSRF, ограничение неудачных попыток входа.
- Создание, изменение, поиск и удаление опросников; 1–50 вопросов, 2–4 варианта, 5–120 секунд.
- Викторины с правильным ответом и баллами; опросы без правильного ответа и без баллов.
- Комнаты с независимым снимком опросника, лобби, участники, таймер, голоса, диаграммы и рейтинг.
- До 1000 баллов за правильный ответ: 500 за правильность, до 500 за скорость. За ошибку и отсутствие ответа — 0.
- Ответ принимается один раз; сервер проверяет дедлайн и текущий вопрос. Верный ответ не передаётся до показа результатов.
- Обновление экрана примерно раз в секунду через HTTP polling. Для небольшой локальной аудитории, без отдельного WebSocket-сервера.
- Возврат игрока после обновления страницы через «Вернуться в мою игру», история последних 12 комнат. Все данные сохраняются в SQLite.

## Данные и эксплуатация

Данные: `storage/quiz.sqlite`. Apache закрывает папку `storage` через `.htaccess`. Для других серверов обязательно запретите HTTP-доступ к этой папке либо задайте `QUIZ_DATA_DIR` с путём вне веб-каталога. Встроенный сервер PHP предназначен для локальной разработки; не публикуйте его в интернете. Для публичного размещения настройте HTTPS, закрытое хранилище и резервные копии. При резервном копировании SQLite останавливайте сервер или используйте SQLite backup API, учитывая WAL.

Шрифт Manrope загружается с Google Fonts; без интернета используется системный шрифт. Все функции игры работают без внешних сервисов.

## Проверка

```powershell
python tests/e2e.py
```

Проверка запускает отдельный PHP-сервер на `127.0.0.1:8099` и изолированную временную базу; рабочие опросники не затрагиваются. В конце сервер и временные файлы удаляются.
