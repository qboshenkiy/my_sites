# Копилка

Личные финансы одного владельца/семьи: расходы и доходы, категории, история по месяцам, общий баланс, месячный бюджет, цели, отметки накоплений, расчёт ежемесячного взноса и рекомендации по собственным записям. Валюта по умолчанию KGS. Суммы в SQLite хранятся в целых сотых долях. Импорта из банка и автоматического чтения банковских SMS нет.

## GitDeck и сервер

После обновления GitDeck до 1.12.0 карточка «Копилка» добавляется автоматически. «Настроить Копилку» устанавливает модуль в `/opt/kopilka`, собирает web и bot, подключает `https://finance.vano.sbena.net` к существующему Caddy. Первоначальный пароль копируется из GitDeck как scrypt-хеш, открытый пароль не передаётся. Повторная настройка сохраняет пароль, `.env`, Compose и том данных. Для установки необходим существующий HTTPS-прокси Marathon/Pulse и DNS на сервер.

Данные в Docker-томе `finance-data` вне кода. Обновление из Git заменяет только `src`, `web`, `requirements.txt`. JSON-экспорт доступен в настройках; для полного восстановления сохраняйте Docker-том при остановленных web и bot. Экспорт не содержит секретов и не является файлом автоматического восстановления.

## Android и Linux

Откройте сайт в Chrome/Chromium → меню → «Установить Копилку». Установленная PWA открывается отдельно и использует общую серверную базу. Сеть нужна для чтения и записи; финансовые данные не кешируются офлайн.

Нативная Android-оболочка и сборка APK: `native/android`. Linux GTK/WebKit-приложение: `native/linux`; установщик `python3 native/linux/install.py`. Все клиенты открывают один HTTPS-сайт и используют общий пароль, без отдельных копий базы.

## Telegram

Создайте **отдельного** бота в BotFather. В GitDeck → Настройки сайта Копилки задайте `TELEGRAM_BOT_TOKEN`, сохраните и перезапустите web и bot. В Копилке → Настройки → Получить код подключения, затем отправьте `/start КОД` своему боту в **личном** чате. Код одноразовый, действует 10 минут. Только один подключённый личный чат имеет доступ. «Отключить Telegram» отзывает доступ и коды.

Команды: `/expense 250 Продукты`, `/income 50000 Зарплата`, `/balance`, `/goals`, `/tips`. Операции бота сразу видны на сайте. Расходы бота попадают в «Другое», текст сохраняется как описание. Без токена bot остаётся запущенным и ожидает настройки, Telegram не подключён. Чужим чатам финансовые данные не выдаются, групповые сообщения игнорируются. Привязка Telegram даёт доступ к общей базе и не зависит от браузерной сессии.

## Проверка

`python3 -m venv /tmp/kopilka-venv; /tmp/kopilka-venv/bin/pip install -r requirements.txt`

Из корня репозитория: `/tmp/kopilka-venv/bin/python kopilka/tests/test_app.py`. Тесты используют временную базу.
