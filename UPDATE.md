# Обновление «Пульса» без потери данных

Используйте **dist/pulse-update.tar.gz** для уже установленного сайта. Полный `pulse-server.tar.gz` предназначен для первой установки. Архив обновления содержит код и ресурсы, но не содержит `.env`, базу, compose-файлы и настройки Caddy.

С компьютера:

```powershell
scp C:/laragon/www/my_project/dist/pulse-update.tar.gz root@2.28.57.159:/root/
```

На сервере, если сайт работает в HTTP-режиме:

```bash
cd /opt/pulse
docker compose exec -T web php /opt/pulse/backup.php /var/lib/pulse/before-v2.sqlite
docker compose cp web:/var/lib/pulse/before-v2.sqlite /root/pulse-before-v2.sqlite
docker compose stop
tar -xzf /root/pulse-update.tar.gz -C /opt/pulse
docker compose up -d --build --wait
```

Если файл резервной копии уже существует, выберите другое имя. Для HTTPS добавьте `-f compose.https.yaml` во всех compose-командах. Не используйте `down -v`: этот флаг удаляет volume с базой.

Таблицы изображений и игровых полей добавляются автоматически. Старые опросники, игры и игроки сохраняются. Изображения хранятся внутри SQLite и входят в резервную копию.

## Новые функции

- Изображение в каждом вопросе: PNG, JPEG, WebP, GIF, до 2 МБ и 4096×4096.
- Формат «Категории и баллы»: кнопка создаёт вопросы за 10, 20, 30, 40, 50; значения можно менять.
- Каждый правильный ответ получает полную стоимость ячейки. Ведущий выбирает ячейку, отвечают все участники.
- Последовательная викторина поддерживает баллы за скорость или фиксированные баллы.
- QR-код в лобби. Открывайте панель через доступный игрокам домен/IP, чтобы QR вёл на этот адрес.
- Отдельная ссылка на экран проектора с кнопкой полного экрана; управление остаётся у ведущего.
- Таблица всех игроков после ответа и в финале. При одинаковых баллах участники разделяют место.

Проекторная ссылка предоставляет только просмотр игры. Передавайте участникам QR/ссылку входа, а не ссылку проектора.


## Импорт викторин из JSON

В панели ведущего нажмите **Импорт JSON**, вставьте текст или загрузите файл и нажмите **Проверить JSON**. Предпросмотр показывает категории, баллы и правильные ответы. Затем можно создать новую викторину сразу или открыть вопросы в обычном редакторе. Ручное создание сохранено.

Поддерживаются `title`, `categories[].title`, `categories[].questions[]`, `question`, `options[].id`, `options[].text`, `options[].isCorrect`, `correctAnswer` и `reference`. Также можно передать плоский массив `questions` с текстовыми вариантами и индексом `correct` (с нуля). Пример JSON доступен прямо в форме.

По умолчанию вопросы внутри категории получают 10, 20, 30, 40, 50 баллов; шаг и время можно выбрать перед импортом. Поля `points` и `seconds` отдельного вопроса имеют приоритет. Ссылки `reference` показываются игрокам после раскрытия ответа и доступны для ручного редактирования. Изображения добавляются файлами через редактор.

Ограничения: 10 МБ, до 50 вопросов, 2–4 варианта ответа. Для викторины нужен один правильный ответ. Неполный JSON, конфликтующие правильные ответы и повторяющиеся ячейки категорий отклоняются до сохранения. Проверка JSON не меняет существующие викторины.

Для установленного GitDeck достаточно обновить модуль «Пульс» из GitHub: новые файлы входят в уже управляемую папку `assets`.


## Бредовуха: выдумки и правда

В редакторе выберите формат **Бредовуха**. У каждого вопроса задайте категорию, вопрос и настоящий ответ. При необходимости добавьте до 10 допустимых написаний через точку с запятой, пояснение и изображение. Можно импортировать обычный JSON с правильными вариантами, выбрав формат **Бредовуха**, либо использовать `mode: "bluff"` и поле `truth` у вопросов (с необязательным массивом `aliases`).

В комнату входят по обычному коду или QR. Нужно минимум два игрока. В первом раунде категорию выбирает первый присоединившийся, затем право выбора переходит по очереди. Из выбранной категории случайно берётся ещё не сыгранный вопрос. На выбор категории даётся 60 секунд, затем она выбирается автоматически; ведущий тоже может выбрать случайную категорию кнопкой.

Все игроки, включая выбравшего категорию, пишут ложные ответы. Совпадение с правдой или допустимым написанием отклоняется с приватным сообщением этому игроку. Проверка игнорирует регистр, различие ё/е, лишние пробелы и разделяющую пунктуацию. Автоматического распознавания синонимов нет — добавляйте их в допустимые написания.

Когда все отправили выдумки или закончилось время, начинается голосование на 30 секунд. Правда и выдумки перемешиваются; авторы и правильность скрыты. Одинаковые выдумки объединяются. Голосовать за свою нельзя. Если несколько человек написали одинаковую выдумку, каждый её автор получает баллы за поверивших ей игроков.

За правду — **1000 баллов**, за каждый голос за свою выдумку — **500**. После голосования раскрываются настоящий ответ, авторы и выбравшие варианты игроки, затем показывается таблица результатов. Ведущий может завершить ввод, раскрыть голосование или перейти к следующему раунду. Игроки, присоединившиеся посреди раунда, участвуют со следующего. Пропустивших ввод не ждут после окончания таймера. Экран проектора поддерживает весь режим, включая категории, ввод, голосование и результаты.

Обновите модуль «Пульс» в GitDeck и перезагрузите страницу. Новые файлы входят в управляемую папку `assets`; миграции таблиц игры выполняются автоматически. Старые викторины и результаты сохраняются.
