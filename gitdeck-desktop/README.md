# GitDeck для Ubuntu

Установите `dist/gitdeck-desktop_1.0.0_all.deb` через «Установку приложений». В меню появится GitDeck. Для сборки: `python3 build.py`.

Откройте ярлык, укажите сервер и пользователя. Пустые поля используют сервер 2.28.57.159, root и порты 22/8120. OpenSSH спросит пароль или парольную фразу ключа в графическом окне. Пароль не сохраняется. Первый ключ сервера требует подтверждения; изменившийся известный ключ SSH отклоняет. Существующие ключи и ssh-agent поддерживаются.

Приложение открывает панель в вашем браузере. Пока окно «GitDeck подключён» открыто, работает SSH-туннель. «Отключиться» закрывает его. Занятый локальный порт не перехватывается. При потере связи показана ошибка. Настройки адреса и пользователя хранятся в ~/.config/gitdeck-desktop; порт панели на сервере задаётся отдельно от локального.

Нужна графическая сессия Ubuntu с Zenity, OpenSSH, Python и браузером. Зависимости указаны в deb. Проверены сборка, структура пакета и синтаксис. Полный вход через графический askpass следует проверить в установленной сессии Ubuntu.
