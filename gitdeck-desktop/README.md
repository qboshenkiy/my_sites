# GitDeck для Ubuntu — 1.1.2

Установите `dist/gitdeck-desktop_1.1.2_all.deb` через установщик приложений Ubuntu поверх версии 1.0.0. Запустите GitDeck из меню. Панель открывается внутри окна GTK/WebKit, внешний браузер не нужен.

В форме уже заполнены сервер, пользователь, порт SSH, локальный порт и порт GitDeck на сервере. Измените нужные значения и нажмите «Сохранить и подключиться». Все пять полей сохраняются и восстанавливаются, в том числе при закрытии окна. Файл настроек ~/.config/gitdeck-desktop/settings.json содержит только параметры подключения, права 0600. Настройки адреса и пользователя версии 1.0.0 переносятся автоматически.

Пароль SSH вводится в отдельном графическом окне. Флажок «Запомнить пароль SSH» использует Secret Service — системную связку ключей Ubuntu, без записи пароля в JSON. Если связка ключей недоступна, показывается предупреждение, вход продолжается без сохранения. «Забыть сохранённый пароль» удаляет пароль выбранного сервера/пользователя/порта. Если пароль неверный, удалите его и подключитесь повторно. Ключи SSH и ssh-agent также поддерживаются; парольные фразы ключей не кешируются этим приложением.

Первый ключ сервера требует подтверждения отпечатка; изменённый известный ключ OpenSSH отклоняет. Туннель слушает только 127.0.0.1. Приложение проверяет /health панели перед открытием, показывает ошибки входа и занятых портов. «Настройки / отключиться» и закрытие окна завершают принадлежащую приложению группу процессов SSH, включая окно запроса пароля. Фоновое подключение отменяется без зависания интерфейса.

Сборка: `python3 build.py`. Зависимости прописаны в deb: python3-gi, GTK 3, WebKit2 4.1, libsecret, OpenSSH и Zenity. Проверки: `python3 tests.py`; создание реального GTK-окна, восстановление значений в форме и загрузка HTML во встроенном WebKit проверены в графической сессии. Полный вход на конкретный SSH-сервер и разблокировку вашей системной связки ключей нужно проверить после установки.

## Обновление без переустановки системного пакета

Версия 1.1.1 поддерживает пользовательскую установку: `python3 install-user.py`. Приложение копируется в ~/.local/share/gitdeck-desktop, ярлык ~/.local/share/applications/gitdeck.desktop имеет приоритет над старым системным ярлыком. Системный пакет не удаляется, настройки подключения сохраняются. Заголовок окна показывает 1.1.1. При занятом локальном порте выбирается ближайший свободный и сохраняется в форме. Для обычной установки также собирается gitdeck-desktop_1.1.1_all.deb.


## Версия 1.1.2

Для сервера 2.28.57.159 значения root/22 из старых настроек автоматически
переносятся в vano-admin/22222. Другие серверы и их явно заданные пользователи
не изменяются. SSH использует ключ из локального ~/.ssh/config, затем пароль
пользователя, если сервер требует оба способа. Пароль веб-панели независим.

Обновление deb поверх прежнего пакета заменяет старые файлы без удаления
пользовательского settings.json, данных WebKit и SSH-ключей. Если раньше
использовался install-user.py, его ярлык ~/.local/share/applications/gitdeck.desktop
нужно убрать из запуска (например, сохранить в резервной копии), чтобы меню
открывало системный пакет. SSH-ключи нельзя помещать в deb или Git.
