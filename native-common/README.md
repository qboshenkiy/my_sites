# Обновления Android

Марафон, Chrono Logos и Vano Remote используют общий модуль обновления. При открытии приложение
проверяет версии не чаще раза в 15 минут. При новой версии предлагает скачать APK,
проверяет SHA-256, package ID, versionCode и совпадение подписывающего сертификата
с установленным приложением, затем открывает системную установку. Android требует
подтверждения пользователя и разрешения установки из этого приложения.

Веб-страницы не могут выбирать APK или запускать установку: JS-мост отсутствует.
Скачивание идёт только по HTTPS с официальных release-адресов этого репозитория.
Cookie сайта и токены не отправляются на GitHub. При недоступности обновлений сайт
продолжает работать. Кнопка ручной проверки есть на экране ошибки подключения.

Один раз установите APK 1.1.0 или новее вместо прежнего приложения. После этого
файлы вручную искать не нужно. Изменения самого сайта уже видны без обновления APK.

Workflow **Publish signed Android updates** автоматически запускается при изменениях
оболочек Android или `native-common` в `main`. Он тестирует три приложения и публикует
их в GitHub Releases. Постоянный ключ хранится зашифрованным секретом Actions
`ANDROID_KEYSTORE_B64`; не удаляйте и не заменяйте его. Ключ совпадает с ранее выданными
локальными APK. Сам ключ не хранится в Git и не передаётся телефону.

Публичный указатель версий:
https://github.com/qboshenkiy/my_sites/releases/download/android-latest/updates.json

APK хранятся в неизменяемых релизах `android-N`. Для прежних тестовых APK, собранных
на GitHub до подключения постоянного ключа, подпись могла отличаться. Android
откажет в обновлении такого APK; перед переустановкой убедитесь, что знаете способ
входа в аккаунт. При обычном обновлении локальных APK данные приложения сохраняются.

## Установка веб-приложений

Общий скрипт `pwa-assist.js` подключён к Пульсу, марафону, Chrono Logos, Штриху и GitDeck.
Предложение оформляется в цветах модуля (`data-pwa-app`) и появляется только после
события браузера `beforeinstallprompt`. Кнопка вызывает системное подтверждение установки.
В Telegram Mini App, встроенных браузерах и нативных Android-оболочках предложение скрыто.
Уже установленная PWA получает отдельное предложение обновления при готовом service worker.

Проверка поведения в Chromium: `node tests/pwa.cjs` из корня репозитория; используется Playwright.
Для окружений с отдельными установками доступны `PLAYWRIGHT_MODULE` и `PLAYWRIGHT_BROWSER`.
