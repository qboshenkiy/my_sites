# Голос книги

Личная аудиобиблиотека для `books.vano.sbena.net`: DOCX/DOC/PDF → проверка текста → голос → MP3. Два способа озвучки:

- **Локальный Piper**: русские голоса Денис и Дмитрий, CPU, без API-ключа, оплаты за символы и передачи текста внешнему сервису. Для установки нужны интернет и место для моделей; сам сервер, его диск и электричество остаются вашими ресурсами. Нейросетевая интонация зависит от голоса, пунктуации и текста; актёрское чтение не обещается.
- **ElevenLabs**: ваш купленный аккаунт, собственный API-ключ, голоса из аккаунта, модель `eleven_multilingual_v2`. Озвучка и проба расходуют лимит ElevenLabs. Книги передаются этому сервису только после выбора режима и подтверждения запуска. Покупка подписки должна включать доступ к API и права на выбранный голос; приложение не обходит ограничения сервиса.

## Возможности

Закрытая паролем библиотека; загрузка или вставка текста; исправление текста перед запуском; настройка голоса, скорости и локальной паузы; проба первых 400 знаков; одна фоновая очередь; готовые части доступны до завершения книги; остановка после текущей части и продолжение с сохранением готового аудио; MP3 всей книги и воспроизведение частей; запоминание позиции в текущем браузере; удаление исходника и аудио. Смена текста/голоса/провайдера требует сохранения и сбрасывает прежнее аудио с подтверждением.

Поддерживаются Word `.docx` и старый `.doc`, PDF **с текстовым слоем**. Сканы без текста требуют предварительного OCR. Защищённые паролем PDF нужно сначала расшифровать. Лимит файла — 30 МБ, текста — 500 000 символов, PDF — 1500 страниц, библиотеки — 40 записей, включая пробы. Большую книгу можно разделить на тома. Копирование из PDF не гарантирует правильный порядок колонок и колонтитулов: проверяйте извлечённый текст.

## Установка на вашем сервере и добавление в GitDeck

Проще всего: обновите сам GitDeck до 1.8.0 или новее. Карточка **«Голос книги»** появится автоматически. Нажмите **«Настроить сайт»**, задайте пароль библиотеки и дождитесь завершения задания в журнале. Повторный запуск сохраняет книги и API-ключ.

Альтернативная установка через терминал на сервере с Docker Compose V2 и установленным GitDeck:

```bash
git clone --depth 1 https://github.com/qboshenkiy/my_sites.git /root/bookvoice-source
bash /root/bookvoice-source/bookvoice/install.sh
```

Если каталог уже есть, сначала выполните `git -C /root/bookvoice-source pull --ff-only`.

Установщик копирует модуль в `/opt/bookvoice`, собирает контейнер, загружает обе бесплатные модели, запускает приложение и предлагает задать пароль (минимум 12 символов). Затем **автоматически регистрирует карточку «Голос книги» в существующем GitDeck** и добавляет отдельный HTTPS-маршрут через текущий Caddy Marathon/Pulse. Существующие записи GitDeck не перезаписываются. Регистрация сохраняет копию конфигурации и отказывается работать во время обновления других модулей. Соответствующий DNS `books.vano.sbena.net` должен указывать на сервер.

В GitDeck: ID `bookvoice`, тип `Docker`, репозиторий `qboshenkiy/my_sites`, ветка `main`, подкаталог `bookvoice`, каталог `/opt/bookvoice`, Compose `compose.yaml`, сервис `web`, основной сервис `web`, пути `src`, `web`, `requirements.txt`. Повторное подключение:

```bash
cd /opt/bookvoice
python3 src/register_gitdeck.py
python3 src/connect_https.py books.vano.sbena.net
```

До настройки HTTPS доступ через SSH-туннель:

```bash
ssh -N -o ExitOnForwardFailure=yes -L 8140:127.0.0.1:8140 root@2.28.57.159
```

Откройте `http://localhost:8140`. Порт контейнера снаружи привязан только к loopback; новый публичный TCP-порт не открывается. Через Docker-сеть Caddy использует `bookvoice-web:8140`. При неоднозначном основном маршруте `web:80` скрипт откажется менять прокси; после исправления стабильного alias актуальным GitDeck повторите подключение. При нескольких прокси можно задать `--proxy ID`.

## Подключение ElevenLabs

Войдите на сайт → **Настройки** → вставьте API-ключ с правами **Text to Speech** и **Voices: read** → «Подключить и загрузить голоса». Это не запускает генерацию. Ключ хранится в `/data/elevenlabs.json` с правами 0600, не возвращается API браузеру и не попадает в Git. Токен присылать в чат не нужно.

В карточке книги выберите «ElevenLabs · мой аккаунт», голос, скорость 0.8–1.2× и сохраните настройки. Начните с пробы. Полная озвучка требует отдельного подтверждения передачи текста и расхода лимита. Счётчик символов и стоимость определяет ElevenLabs; приложение не обещает фиксированную цену. Локальная настройка паузы относится к Piper; ElevenLabs интерпретирует абзацы своей моделью.

При ошибке API задача останавливается. Автоматического повторения платного запроса или переключения на другой сервис нет. После аварийного перезапуска незавершённая ElevenLabs-задача ставится на паузу: проверьте историю аккаунта перед продолжением, так как оборванный запрос мог уже расходовать лимит. Успешно сохранённые части не пересоздаются. Удаление ключа доступно после остановки облачных задач; готовое аудио остаётся.

## Данные, ресурсы и обновление

Docker-тома `book-data` (SQLite, документы, аудио, пароль, ключ) и `voice-models` (модели) сохраняются при обновлении через GitDeck. Не используйте `docker compose down -v`. Тома **не являются резервной копией**; копируйте их отдельно. При восстановлении SQLite сначала остановите сервис и сохраняйте согласованный комплект файлов БД/WAL. Перезапуск модели загрузки не требует повторной оплаты или ключа.

```bash
cd /opt/bookvoice
docker compose exec web python src/download_models.py
docker compose exec web python src/app.py password
```

Лимит контейнера: 2 ГБ памяти, 1.5 CPU; один работник озвучки. Настраивается в Compose. Обработка большой книги может занять время; скорость зависит от CPU. Мягкий лимит хранения `MAX_STORAGE_MB=4096`, для подготовки целого MP3 нужно также место под второй файл. При нехватке места задача останавливается с объяснением. На паузе уже отправленная часть заканчивается; сохранённые части остаются доступными.

Если библиотека доступна только по HTTPS, установите `COOKIE_SECURE=1` в `.env` и пересоздайте сервис. При таком режиме HTTP-туннель не поддерживает вход без HTTPS. Все файлы, аудио и настройки защищены паролем и проверкой сессии; операции требуют CSRF-токен.

## Локальная проверка

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r requirements.txt
# Установите также ffmpeg, poppler-utils, antiword из пакетного менеджера.
.venv/bin/python -m unittest discover -s tests -v
DATA_DIR=./data MODEL_DIR=./models .venv/bin/python src/app.py password
DATA_DIR=./data MODEL_DIR=./models .venv/bin/python src/download_models.py
DATA_DIR=./data MODEL_DIR=./models .venv/bin/python src/app.py serve
```

Адрес `http://localhost:8140`. Модели не коммитятся. Проверены настоящая локальная генерация Piper, извлечение DOCX/PDF, очередь/пауза/продолжение, доступ к MP3 с Range, авторизация/CSRF, хранение ключа, явное разрешение ElevenLabs, остановка после сбоя API, регистрация GitDeck и подготовка HTTPS. В тестах ElevenLabs используется фиктивный транспорт: реальный API-ключ не предоставлялся, платные запросы не выполнялись. Docker и реальное развёртывание на сервере проверяются при установке; локальная проверка использовала Python и FFmpeg напрямую.
