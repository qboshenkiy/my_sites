# Сүйлө

Уроки кыргызского языка для русскоязычных пользователей. В приложении 14 стартовых уроков и проверок A0–B1, 12 видов заданий, словарь с интервальным повторением, 6 диалоговых ситуаций и статистика. Индекс последнего задания, XP, слова и ошибки хранятся в IndexedDB.

## Запуск и установка

```bash
cd suilo
npm ci
npm run dev
```

Проверка production-сборки и PWA: `npm run build && npm run preview`. После первого открытия дождитесь загрузки приложения. Карта, уроки, словарь и основные аудиозадания доступны без сети. Установка на Android и компьютере доступна через меню Chrome или Edge. В Safari на iPhone выберите «Поделиться» → «На экран “Домой”».

Android требует Node 24, JDK 21 и Android SDK Platform 36. При установленных SDK и JDK:

```bash
npm ci
npm run android
cd android
./gradlew assembleDebug
```

APK находится в `android/app/build/outputs/apk/debug/app-debug.apk` относительно каталога `suilo`. Это тестовая сборка, подписанная ключом отладки. Для магазина нужна отдельная подписанная release-сборка.

## GitDeck, HTTPS и Guard

Войдите по SSH на существующий сервер GitDeck и выполните:

```bash
checkout=$(mktemp -d)
git clone --depth 1 --branch suilo https://github.com/qboshenkiy/my_sites.git "$checkout/my_sites"
sudo python3 "$checkout/my_sites/suilo/ops/install.py"
```

Установщик создаёт контейнеры в `/opt/suilo`, подключает `https://suilo.vano.sbena.net/` к общему прокси и добавляет карточку **«Сүйлө · кыргызский язык»**. Входящие запросы проходят через существующий request gate Guard и попадают в журнал Caddy. Установщик требует активные службы Guard, проверяет конфигурацию Caddy и восстанавливает старый маршрут при ошибке. Приложение не публикует собственные порты. Для обновлений используйте кнопку **«Обновить из Git»** на карточке. Секреты в серверном `.env` сохраняются.

После установки откройте сайт с обычного устройства и проверьте HTTPS. Проверка служебных путей и создание частых запросов на рабочем сервере могут заблокировать ваш IP по правилам Guard.

## Telegram

В GitDeck откройте **Сүйлө → Настройки сайта**, сохраните секрет `TELEGRAM_BOT_TOKEN` для [@duolingo_by_vano_bot](https://t.me/duolingo_by_vano_bot) и примените настройки. Пересоздайте сервис `bot` через обновление карточки, если сохранение не сделало этого. Бот сверяет имя через `getMe`, настраивает меню **«Сүйлө»**, отвечает на `/start`, `/app` и `/help` кнопкой Mini App. Для этого токена должен работать один процесс polling без webhook. Telegram WebView открывает тот же HTTPS-сайт и хранит локальный прогресс в своём браузерном контексте. В меню BotFather можно дополнительно включить Main Mini App и указать тот же URL. [Документация Telegram](https://core.telegram.org/bots/webapps)

## Необязательная синхронизация

Примените `ops/supabase.sql` к своему проекту Supabase. В Auth добавьте `https://suilo.vano.sbena.net/?page=settings` в разрешённые Redirect URLs. Задайте `VITE_SUPABASE_URL` и публичный `VITE_SUPABASE_ANON_KEY` до сборки. В Docker они передаются через серверный `.env`. После входа по ссылке из письма кнопка в настройках объединяет уроки, XP, словарь и ошибки. Повторная отправка не удваивает XP. Настройки и черновик урока остаются локальными. В Android и Telegram для привязки по email удобнее сначала воспользоваться обычным браузером.

## Учебный материал и озвучка

Разделы A0–B1 содержат стартовые темы. Для свободного диалога локальные правила проверяют конструкции и типичные ошибки. Для незнакомых формулировок предлагается пример для сравнения, после чего можно продолжить со своим ответом. Микрофон использует распознавание `ky-KG`, если браузер и устройство его предоставляют. При сбое можно ввести произнесённую фразу вручную или пропустить задание.

Формы приветствия и знакомства сверены с программой Кыргызской академии образования. Материал курса расширяется в `src/course.ts`, диалоги — в `src/Conversation.tsx`. [Программа Кыргызской академии образования](https://kao.kg/wp-content/uploads/2020/06/%D0%BF%D1%80%D0%BE%D0%B3%D1%80%D0%B0%D0%BC%D0%BC%D0%B0-10-11-%D0%BA%D0%BB%D0%B0%D1%81%D1%81%D0%B0-25.12.pdf)

MP3 в `public/audio/` синтезированы моделью Meta MMS Kyrgyz, выпущенной по CC BY-NC 4.0. Учитывайте условия модели при дальнейшем использовании озвучки. [Модель и лицензия](https://huggingface.co/facebook/mms-tts-kir)
