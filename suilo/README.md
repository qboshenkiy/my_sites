# Сүйлө — слова для живого общения

## Telegram: вход и память

Основной запуск — кнопка Mini App у [@duolingo_by_vano_bot](https://t.me/duolingo_by_vano_bot).
Аккаунт создаётся при первом открытии по проверенным данным Telegram: пароль и email
не нужны. Сервер проверяет HMAC initData отдельным токеном бота, время авторизации
(до часа, не более 30 секунд в будущем) и ID пользователя. Неподписанные данные и
поля initDataUnsafe не используются для входа. Хранятся Telegram ID, имя, username,
прогресс и хеши случайных сессий. Телефон и переписка не запрашиваются.

Прогресс хранится в SQLite `/data/learning.sqlite` отдельного сервиса `api`, в постоянном
томе `telegram-data`. Он не зависит от переустановки Telegram или кеша WebView.
На другом устройстве открывайте тот же Mini App под тем же Telegram-аккаунтом.
Автосохранение объединяет изменения по времени и проверяет ревизию, чтобы одновременная
работа не перезаписывала прогресс молча. Запросы объединяются с задержкой 4 секунды;
перед закрытием дождитесь статуса «прогресс сохранён на сервере». При сбое шаги остаются
на устройстве до следующей удачной синхронизации. Вход при новом открытии требует сети.
Старая локальная очередь урока остаётся на устройстве; на другом устройстве доступны
изученные слова, интервалы, результаты уроков и личные карточки, но не незавершённый шаг.

Разные аккаунты имеют разные записи на сервере и разные локальные ключи IndexedDB.
Старый анонимный прогресс не переносится в чужой аккаунт автоматически: в настройках
есть явная кнопка переноса занятий этого устройства. Без Telegram приложение также
работает локально. Supabase для входа и сохранения через Telegram не нужен.

В нативном Telegram используются защищённая HttpOnly cookie и сеанс. Для Telegram Web,
где сторонние cookies могут блокироваться, сеанс также передаётся в Authorization;
этот токен хранится только в памяти страницы. API не кешируется, не разрешает CORS,
проверяет Origin и специальный заголовок для изменений. Тела запросов, initData,
cookies и токены не пишутся в журналы. Сервис API не публикует порт на хосте: только
Caddy → Guard → nginx → внутренняя сеть Docker → API.

### Однократное включение на уже установленном сервере

У старой установки был только статический сайт и бот, поэтому одного обновления
TypeScript недостаточно. Из **проверенного checkout этого выпуска** на сервере:

```sh
sudo python3 suilo/ops/enable_telegram.py --branch codex/suilo-vocabulary
```

Скрипт проверяет карточку, отсутствие заданий GitDeck и работающий Guard, сохраняет
предыдущие инфраструктурные файлы, добавляет только `compose.gitdeck-telegram.yaml`
и сервис `api`, проверяет Compose и ставит обновление в стандартную очередь GitDeck.
Базовые Compose, `.env`, Caddy и чужие сайты не подменяются. В GitDeck заранее должен
быть задан токен именно бота Сүйлө. Ветка должна быть опубликована в GitHub до запуска.
При первом развёртывании можно использовать обновлённый `ops/install.py`.

При ошибке до изменения конфигурации файлы возвращаются. После постановки задания
проверяйте его результат в GitDeck: автоматический откат GitDeck возвращает код;
новый том с данными не удаляется. Генерируемая копия инфраструктуры остаётся в
`/opt/suilo/.telegram-infrastructure-before.json` вне управляемых путей кода.

Дальше обычные обновления выполняются кнопкой **«Обновить из Git»**. Generic Docker
в GitDeck сохраняет код, но не делает автоматическую копию внешней SQLite. Создать
консистентную копию внутри постоянного тома можно так:

```sh
cd /opt/suilo
sudo docker compose -f compose.yaml -f compose.gitdeck-https.yaml -f compose.gitdeck-telegram.yaml exec -T api python /app/server.py backup
```

Она появится в `/data/backups/` тома `telegram-data`; отдельную копию следует забрать
с сервера. Живую SQLite не копируйте простым `cp` без учёта WAL.

## Версия 1.1: обучение по 1000 словам

Главный экран теперь открывает короткое словарное занятие, а не карту стартовых уроков.
Встроены 1000 разных записей (слова и выражения), 25 тем по 40 записей. Ручной импорт
не требуется. По умолчанию — 5 новых слов в день; в настройках доступны 3, 5, 10 и 15.
Это тематическая учебная подборка, не статистический частотный рейтинг.

Порядок занятия: знакомство со словом и переводом → выбор значения → ввод кыргызского
слова по русской подсказке. Новые слова сначала показываются с переводом: приложение
не требует угадывать незнакомое. Есть кнопки ң, ө, ү и «Не помню». Для 42 слов добавлены
примеры в контексте; для части частых глаголов — готовые формы с переводами.
Примеры не заменяют полный курс грамматики и не генерируются автоматически.

Очередь включает до 10 просроченных слов перед новыми. Уверенные ответы в заданиях
на вспоминание получают интервалы 1, 3, 7, 14 и 30 дней. «С трудом» возвращает слово
через 4 часа, ошибка или подсказка — через 10 минут. Узнавание перевода не увеличивает
интервал; после ошибки правильный ответ в том же занятии не делает слово закреплённым.
На одно слово добавляется максимум одна дополнительная попытка за занятие.
«Закреплено» означает три успешных интервальных повторения, а не сертификацию знания.

Сохраняются каждый завершённый шаг и очередь. После закрытия приложения можно
продолжить с того же задания. Новое поле vocabulary добавлено в прежнюю IndexedDB
без удаления личных карточек, уроков, настроек и ошибок. Облачное объединение сохраняет
более новую карточку; дневные счётчики объединяются консервативно через максимум,
поэтому независимые занятия на двух устройствах могут быть недосчитаны. Незавершённая
очередь остаётся локальной. Словарь фильтруется по теме, статусу и тексту; открытие
карточки не меняет прогресс. При большом результате показываются первые 100 записей.

Настройки → «Резервная копия словаря»: экспорт и проверяемый импорт JSON. Копия
содержит только обучение по готовой тысяче, без личных карточек и старых уроков.
В Android сохранение проходит через системный выбор документа без доступа ко всему
хранилищу; в браузере — обычная загрузка файла. Импорт объединяет карточки по времени
изменения, не стирая более новые результаты. Хранилища APK и браузера отдельные; внутри Telegram прогресс дополнительно сохраняется на сервере.

APK содержит словарь и приложение внутри, сеть для обучения не нужна. Веб-версия
доступна офлайн после успешного кеширования: приложение показывает уведомление о
готовности. Обновление PWA предлагается кнопкой и не перезапускает занятие само.
APK обновляется отдельной установкой; обновление сайта в GitDeck не обновляет APK.
Озвучка использует прежние записи и кыргызский голос устройства, если он установлен;
готовых аудиозаписей всех 1000 слов в этом выпуске нет.

## Обновление через GitDeck и Guard

В GitDeck используйте существующую карточку **Сүйлө**, репозиторий `my_sites`, папку
`suilo`, Compose `compose.yaml`, сервисы `web`, `bot` и `api`. Выберите ветку с этим выпуском
и выполните **«Обновить из Git»**. Обновление использует существующие разрешённые
пути из `ops/install.py`: новые материалы находятся в `src/`, необходимые веб-файлы
в `public/` и `ops/`. `.env`, Compose, домены и токены не подменяются. Повторно запускать
установщик для уже установленного сайта не нужно.

HTTPS продолжает идти через общий Caddy и `guard-sensitive.caddy` с request gate.
Прямые публичные порты модуля не добавлены, правила и ограничения Guard не меняются.
Статика загружается один раз, проверки слов выполняются локально: нет опроса сервера
на каждый ответ. Фактическую установку и состояние Guard нужно проверить на сервере
после обновления; локальные тесты маршрута не подтверждают состояние работающего хоста.

## Проверки разработки

```sh
cd suilo
npm ci
npm test
npm run build
python3 -m unittest discover -s ops -p test_ops.py
npm run android
cd android
./gradlew --no-daemon --max-workers=2 lintDebug assembleDebug
```

Node 24, JDK 21 и Android SDK 36. `npm run android` пересобирает веб и синхронизирует
его с Android; простого Gradle build после изменения TypeScript недостаточно.
Идентификатор `net.sbena.vano.suilo` и origin Android сохранены, versionCode повышен до 2.
Для обновления поверх прежнего APK нужна прежняя подпись. Отладочная сборка использует
локальный debug.keystore; распространение для магазина требует release-подписи.

# Предыдущие возможности и первоначальная установка

Уроки кыргызского языка для русскоязычных пользователей. В приложении 14 стартовых уроков и проверок A0–B1, 12 видов заданий, словарь с интервальным повторением, 6 диалоговых ситуаций и статистика. Индекс последнего задания, XP, слова и ошибки хранятся в IndexedDB.

## Запуск и установка

```bash
cd suilo
npm ci
npm run dev
```

Проверка production-сборки и PWA: `npm run build && npm run preview`. После первого открытия дождитесь загрузки приложения. Карта, уроки, словарь и основные аудиозадания доступны без сети. Установка на Android и компьютере доступна через меню Chrome или Edge. В Safari на iPhone выберите «Поделиться» → «На экран “Домой”».

Android требует Node 24, JDK 21 и Android SDK Platform 36. При установленных SDK и JDK:

```bash
npm ci
npm run android
cd android
./gradlew assembleDebug
```

APK находится в `android/app/build/outputs/apk/debug/app-debug.apk` относительно каталога `suilo`. Это тестовая сборка, подписанная ключом отладки. Для магазина нужна отдельная подписанная release-сборка.

## GitDeck, HTTPS и Guard

Войдите по SSH на существующий сервер GitDeck и выполните:

```bash
checkout=$(mktemp -d)
git clone --depth 1 --branch suilo https://github.com/qboshenkiy/my_sites.git "$checkout/my_sites"
sudo python3 "$checkout/my_sites/suilo/ops/install.py"
```

Установщик создаёт контейнеры в `/opt/suilo`, подключает `https://suilo.vano.sbena.net/` к общему прокси и добавляет карточку **«Сүйлө · кыргызский язык»**. Входящие запросы проходят через существующий request gate Guard и попадают в журнал Caddy. Установщик требует активные службы Guard, проверяет конфигурацию Caddy и восстанавливает старый маршрут при ошибке. Приложение не публикует собственные порты. Для последующих обновлений используйте кнопку **«Обновить из Git»** на карточке. Секреты в серверном `.env` сохраняются.

После установки откройте сайт с обычного устройства и проверьте HTTPS. Проверка служебных путей и создание частых запросов на рабочем сервере могут заблокировать ваш IP по правилам Guard.

## Telegram

В GitDeck откройте **Сүйлө → Настройки сайта**, сохраните секрет `TELEGRAM_BOT_TOKEN` для [@duolingo_by_vano_bot](https://t.me/duolingo_by_vano_bot) и примените настройки. Пересоздайте сервис `bot` через обновление карточки, если сохранение не сделало этого. Бот сверяет имя через `getMe`, настраивает меню **«Сүйлө»**, отвечает на `/start`, `/app` и `/help` кнопкой Mini App. Для этого токена должен работать один процесс polling без webhook. Telegram WebView открывает тот же HTTPS-сайт; вход и серверное сохранение описаны выше. В меню BotFather можно дополнительно включить Main Mini App и указать тот же URL. [Документация Telegram](https://core.telegram.org/bots/webapps)

## Необязательная синхронизация

Примените `ops/supabase.sql` к своему проекту Supabase. В Auth добавьте `https://suilo.vano.sbena.net/?page=settings` в разрешённые Redirect URLs. Задайте `VITE_SUPABASE_URL` и публичный `VITE_SUPABASE_ANON_KEY` до сборки. В Docker они передаются через серверный `.env`. После входа по ссылке из письма кнопка в настройках объединяет уроки, XP, словарь и ошибки. Повторная отправка не удваивает XP. Настройки и черновик урока остаются локальными. В Android и Telegram для привязки по email удобнее сначала воспользоваться обычным браузером.

## Учебный материал и озвучка

Разделы A0–B1 содержат стартовые темы. Для свободного диалога локальные правила проверяют конструкции и типичные ошибки. Для незнакомых формулировок предлагается пример для сравнения, после чего можно продолжить со своим ответом. Микрофон использует распознавание `ky-KG`, если браузер и устройство его предоставляют. При сбое можно ввести произнесённую фразу вручную или пропустить задание.

Формы приветствия и знакомства сверены с программой Кыргызской академии образования. Материал курса расширяется в `src/course.ts`, диалоги — в `src/Conversation.tsx`. [Программа Кыргызской академии образования](https://kao.kg/wp-content/uploads/2020/06/%D0%BF%D1%80%D0%BE%D0%B3%D1%80%D0%B0%D0%BC%D0%BC%D0%B0-10-11-%D0%BA%D0%BB%D0%B0%D1%81%D1%81%D0%B0-25.12.pdf)

MP3 в `public/audio/` синтезированы моделью Meta MMS Kyrgyz, выпущенной по CC BY-NC 4.0. Учитывайте условия модели при дальнейшем использовании озвучки. [Модель и лицензия](https://huggingface.co/facebook/mms-tts-kir)
