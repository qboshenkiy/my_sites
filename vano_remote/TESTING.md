# Проверки версии 0.1

Выполнено:

- Android `:app:assembleDebug` — успешно, APK собран для Android 11+.
- Windows EXE собран PyInstaller, запуск `VanoRemote.exe --smoke-test` завершился с кодом 0.
- Окно Windows-клиента создано и визуально проверено.
- 9 тестов Python — успешно: обмен в обе стороны, неверный секрет, изменение пакета, повтор, пакет прошлой сессии, отражение пакета, проверка доступа relay, дублирование клиента, отключение пары.
- Код шифрования из фактического Android `Link.java` запущен на JVM: расшифровал пакет Python, его собственный пакет расшифрован Python, производные ключи совпали. Проверен также текст на русском.
- Docker Compose прошёл `config --quiet`.

Не подтверждено:

- Android Lint не завершён: сетевой запуск задержался на загрузке библиотек анализатора; offline-запуск сообщил об отсутствии `intellij-core-31.13.1.jar` и `kotlin-compiler-31.13.1.jar`. Это отдельная проверка от успешной сборки APK.
- Docker-образ локально не запускался: Docker Engine на рабочем компьютере недоступен. Сам relay проверен локально через aiohttp.
- APK не устанавливался на физический Redmi, отпечаток и разрешения HyperOS ещё не проверены на устройстве.
- Сквозное управление реальным Windows-компьютером и Redmi через Hetzner ещё не проверено. Сервер своего приложения на Hetzner не развёрнут; существующая установка RustDesk не менялась.
- Независимого аудита безопасности нет.

Следующая проверка: разместить relay за существующим HTTPS-прокси, установить клиенты, выполнить привязку, проверить отпечаток, управление в обе стороны, отключение из уведомления и отзыв телефона из Windows.
