# Результаты теста Pulse из Telegram

После личного прохождения бот присылает кнопки «Результат на сайте» и «Показать правильные ответы». Первая открывает конкретную работу, включая гостевую; вторая присылает разбор всех вопросов в личный чат: свой ответ, правильный ответ, верно/неверно и пояснение из опросника. Опросы без оценки не обозначаются как ошибки.

При завершении группового теста кнопка «Мой результат» ведёт в личный чат бота. Бот находит работу по Telegram отправителя: чужие ответы в группу не отправляются. Уже существующая команда организатора для общего разбора сохранена.

Баллы и правильные ответы доступны после публикации результатов организатором. До публикации и после её отмены ссылка показывает только подтверждение сдачи. Персональная ссылка действует 30 дней; новую можно получить кнопкой «Мой результат» в боте. Она даёт доступ только к чтению этой работы и не позволяет изменить ответы. Для генерации ссылок нужен HTTPS APP_URL Pulse. Секрет находится во фрагменте ссылки и проверяется сервером при отдельном запросе; в базе хранится его хеш.

На сайте неверный выбранный вариант выделен красным и подписан «Ваш ответ — неверно», правильный выделен зелёным. Для каждого вопроса есть общий статус, включая неполный набор правильных вариантов и отсутствие ответа.

Проверки: `python3 tests/forms.py` (PHP/SQLite, фиктивный Telegram), `node tests/forms_review.cjs` (разбор одиночного/множественного выбора, пропуск, опрос и экранирование), `python3 tests/standings.py`. Реальных сообщений при проверках не отправлялось. В браузере проверено отображение на примере работы, включая ширину 390 px.

Обновление: Pulse вместе с его ботом через GitDeck. Переустанавливать приложение не требуется.
