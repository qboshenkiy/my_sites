# Результаты теста Pulse из Telegram

В Telegram кнопка «Мои результаты» и команда `/results` открывают личный список тестов с процентами и датами, по восемь на страницу. Карточка результата показывает процент, баллы и число верных ответов. После личного прохождения бот присылает кнопки «Результат на сайте» и «Показать правильные ответы». Первая открывает конкретную работу, включая гостевую; вторая присылает разбор всех вопросов в личный чат: свой ответ, правильный ответ, верно/неверно и пояснение из опросника. Опросы без оценки не обозначаются как ошибки.

При завершении группового теста кнопка «Мой результат» ведёт в личный чат бота. Бот находит работу по Telegram отправителя: чужие ответы в группу не отправляются. Уже существующая команда организатора для общего разбора сохранена.

По умолчанию личный результат открывается сразу после сдачи всех ответов, в том числе гостю на сайте. Видны процент, баллы, свои ответы, правильные варианты и местописания. До сдачи правильные ответы и местописания не передаются участнику. Эта настройка включается и для существующих тестов при обновлении. Организатор может отключить «Результат сразу» в управлении тестом, тогда разбор откроется после публикации. Публикация по-прежнему управляет закреплением результатов в общем рейтинге. Персональная ссылка действует 30 дней; новую можно получить кнопкой «Мой результат» в боте. Она даёт доступ только к чтению этой работы и не позволяет изменить ответы. Для генерации ссылок нужен HTTPS APP_URL Pulse. Секрет находится во фрагменте ссылки и проверяется сервером при отдельном запросе; в базе хранится его хеш.

В редакторе вопроса поле «Местописание или пояснение» сохраняет до 200 символов. При JSON-импорте используется существующее поле `reference`. Самостоятельный тест хранит копию опросника, поэтому для новых местописаний в уже созданном тесте нужно создать новую ссылку из обновлённого опросника.

На сайте неверный выбранный вариант выделен красным и подписан «Ваш ответ — неверно», правильный выделен зелёным. Для каждого вопроса есть общий статус, включая неполный набор правильных вариантов и отсутствие ответа.

Проверки: `python3 tests/forms.py` (PHP/SQLite, фиктивный Telegram), `node tests/forms_review.cjs` (разбор одиночного/множественного выбора, пропуск, опрос и экранирование), `python3 tests/standings.py`. Реальных сообщений при проверках не отправлялось. В браузере проверено отображение на примере работы, включая ширину 390 px.

Обновление: Pulse вместе с его ботом через GitDeck. Переустанавливать приложение не требуется.
