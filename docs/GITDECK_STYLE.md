# GitDeck: графит и бирюза

Выпуск меняет палитру панели, навигации, кнопок, графиков, диалогов, таблиц и меню установки. Карточки разделены спокойными границами, информационные подписи контрастнее. На телефоне сохраняется нижняя навигация.

Добавлены статус последней установки на карточке и фильтр: ошибка установки, обновляется, версия установлена, без версии. Поиск и фильтр работают совместно, рядом показано число найденных проектов. «Версия установлена» означает наличие зафиксированного коммита, а не проверку доступности сайта. Последняя неуспешная установка остаётся видимой даже при сохранённой предыдущей версии.

## Следующие полезные функции

1. **Проверка готовности каждого проекта.** Отдельно HTTPS сайта, работник бота и срок сертификата; показывать причину сбоя и последнее успешное время. Имеющиеся метрики сервера и состояния Docker не заменяют эти проверки.
2. **Резервные копии по расписанию.** Для каждой базы дата копии, размер и проверка восстановления; хранение отдельной копии вне сервера. Сейчас копии связаны с установкой обновлений.
3. **Единый список новых изменений.** Сравнение установленного коммита с выбранной веткой для всех проектов, с кратким описанием того, что придёт в обновлении. Сейчас ветки и версии просматриваются по проектам отдельно.
4. **Очередь обновлений.** Выбранные проекты обновляются по одному; при ошибке очередь приостанавливается, результат и доступный откат видны на одном экране.

В этом выпуске реализованы оформление, статусы и фильтр. Остальные пункты — предложения следующего этапа. Проверены серверные тесты GitDeck, UI-обработчики и вычисление статуса; в браузере — демонстрационный режим с отключённым развёртыванием.
