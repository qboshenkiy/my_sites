# Интерфейсы модулей: аудит и план доработок

Дата: 27 октября 2026. Репозиторий: `my_sites`.

## Что проверялось

Навигация и положение основных действий, понятность статусов, иконки, иерархия текста,
состояния без данных, длинные таблицы, мобильные меню и доставка файлов через существующие Docker/GitDeck-обновления.
Цвета проектов сохраняются: Pulse — сиреневый, Marathon/«Молоко» — зелёный, Chrono Logos — тёмный с золотым,
GitDeck — тёмный с фиолетовым, «Штрих» — светлый. Общие правила не превращают продукты в одинаковые экраны.

Веб-панели проверяются на локальных тестовых данных. Это не изменение данных действующих сайтов.
Для Chrono Logos локально проверяется настоящий шаблон оболочки и меню с заглушкой содержимого,
а не все игровые маршруты CodeIgniter. Vano Remote проверен по исходникам Windows/Android;
его нативные клиенты в Ubuntu не пересобирались и не проверялись на устройствах.

## Общие обнаруженные проблемы и выполненные изменения

| Проблема | Что сделано |
|---|---|
| В меню смешаны SVG, Unicode и эмодзи | Единый локальный набор контурных SVG: сетка 24×24, толщина 1.75 px, один размер навигационных иконок |
| Символы по-разному выглядят в Windows, Ubuntu и Android | Иконки основных меню и показателей больше не зависят от глифов установленного шрифта |
| Неодинаковые размеры и выравнивание элементов | Общие размеры иконок, интервалы, высота основных кнопок на телефоне от 44 px |
| Декоративные карточки вытесняют полезную информацию | В Pulse — быстрые переходы к задачам; в боковых меню — контекст; в «Молоке» — действия дежурного вместо большой бутылки |
| Два разных мобильных меню в Pulse | Удалена старая дополнительная компактная навигация на экранах тестов и ведомостей; остаётся один выезжающий список |
| Закрытое мобильное меню остаётся доступным клавиатурой | Закрытая панель получает inert/aria-hidden; добавлены управление фокусом, Escape и переход к содержимому |
| Интерфейс Chrono выбирается по User-Agent | Общая оболочка и доступ к полному меню определяются шириной окна; изменение ширины не требует нового устройства |
| Длинные ведомости неудобны на телефоне | В Marathon имя закреплено при прокрутке; в общем рейтинге Pulse компактные три столбца с отдельным раскрытием подробностей |
| Мобильные вкладки теряются при прокрутке | В «Молоке» и GitDeck — пять подписанных нижних вкладок с одинаковыми иконками |
| GitDeck описывает сторонний проект как саму панель | Отдельные описания generic Docker и «Молока»; текст о копии кода больше не обещает резервирование всех баз |
| Новые файлы могут не попасть в старый установщик | UI-файлы поставляются внутри assets/web; GitDeck также получает их во встроенном HTML-пакете |

Общий источник: `native-common/ui-icons.json`, `native-common/ui.js`, `native-common/ui.css`.
Копии для отдельных модулей: `python3 tools/sync_ui.py`. Затем обновляется встроенный пакет GitDeck:
`python3 tools/sync_pwa.py`. Runtime-зависимости от CDN и новых библиотек не добавлены.

Логотипы, иллюстрации книг и изображения игровых карточек не являются интерфейсными пиктограммами:
их художественная толщина не выравнивается принудительно. Унифицированы именно управляющие элементы.

## Pulse

**Исправлено в этом выпуске**

- Одинаковые иконки меню, показателей, кнопок выхода/редактирования и общего рейтинга.
- Понятные быстрые переходы: самостоятельные тесты, история игр, общий рейтинг.
- Контекст гостя отличается от кабинета вошедшего участника.
- Один мобильный drawer вместо двух конкурирующих вариантов.
- Отдельная общая таблица закреплённых результатов; место, процент, баллы, участие и оценки по тестам.
- Результаты внутри ведомости идут по баллам, общий рейтинг — по проценту, а не по алфавиту.
- Публикация фиксирует снимок; последующее редактирование не меняет опубликованные баллы без повторной публикации.

**Следующие доработки, по приоритету**

1. **Группы и периоды рейтинга.** Отдельный рейтинг команды/потока/месяца. Сейчас общий знаменатель включает все опубликованные тесты, пропуски дают 0. При нескольких группах это нужно разделить явно.
2. **Карточка участника с деталями процента.** Баллы по заданиям, пропуски и история публикаций в одном месте; переход из строки рейтинга.
3. **Импорт ведомости из CSV с предварительной сверкой имён.** Показывать несовпадения и возможные дубликаты до сохранения; не связывать личности только по совпавшему имени.
4. **Единый экран события.** Комната, тест по ссылке, сопоставление аккаунтов и публикация итога как последовательные шаги с готовностью каждого шага.
5. **Фильтры общего рейтинга и режим проектора.** Участники видят свою строку сразу; организатор может открыть крупную таблицу на экран.
6. **Короткая диагностика Telegram-входа.** Раздельные причины: сессия, подпись Mini App, связь с Marathon, отсутствие привязки; понятное действие для каждой причины.

## Marathon («Глава»)

**Исправлено**

- Единые иконки меню, читаемые подписи и размеры.
- Вместо декоративной цитаты — текущая неделя и подсказка по работе.
- Убрано наложение текста в боковой панели: длинные подписи не получают размер шрифта иконки, блоки не сжимаются поверх друг друга.
- В длинной ведомости закреплён столбец участника. Сама таблица прокручивается, страница целиком не растягивается.

**Следующие доработки**

1. **Короткий статус текущей недели для участника.** Осталось глав, срок, темп и одна основная кнопка отметки; детали и архив — ниже. Существующие показатели темпа стоит собрать в один блок.
2. **Фильтры команды.** Без Telegram, не начали, отстают, выполнили, архив; сохранение фильтров при возвращении из профиля.
3. **Режим карточек на телефоне вместо восьми столбцов.** В строке — имя, главы/план, статус; кнопки внесения/выполнения доступны после раскрытия.
4. **Предварительный просмотр приглашения и напоминания.** Показывать человека, текст и канал до отправки; очередь массовых сообщений с результатами доставки.
5. **Явное разделение текущего круга и накопленного итога.** Не смешивать главы, дни, завершённые круги и архив страниц/минут.
6. **Закреплённая панель недели.** Выбранная неделя, её план и открытость ввода остаются видны при прокрутке ведомости.

## Chrono Logos

**Исправлено**

- SVG из общего набора, включая мобильные вкладки.
- Нормальная адаптация окна вместо двух разных версий, выбранных по User-Agent.
- Полное боковое меню доступно на телефоне, а не только четыре сокращённые вкладки.
- Черновой модуль Draw явно помечен как «скоро», объясняет отсутствие механики и предлагает перейти к готовым играм.
- У меню есть состояние aria-expanded, Escape, затемнение и корректная прокрутка.

**Следующие доработки**

1. **Экран готовности комнаты.** Код, QR, подключённые игроки, готовность ведущего и понятная причина, почему старт недоступен.
2. **Короткие этапы редактора.** Основные данные → карточки → проверка → публикация. Текущие формы можно представить как один сценарий.
3. **Мобильная раскладка карточек.** Убрать необходимость точного перетаскивания; команды перемещения должны быть крупными и иметь видимое состояние выбранной позиции.
4. **Единые карточки статусов.** Черновик/опубликовано, ожидание/игра/завершено и права на управление объясняются одинаково в каталоге и комнатах.
5. **Диагностика подключения в игре.** Последний успешный обмен, восстановление соединения, сохранность хода; статус не должен выглядеть как команда начать игру заново.
6. **Отдельный аудит игрового поля на телефоне.** Нужна проверка реальных длинных хронологий и комнат на устройстве, а не только оболочки.

## GitDeck

**Исправлено**

- Единые иконки модулей, мониторинга и меню.
- Нижняя навигация на телефоне; подписи сохранены, вкладки не превращаются в неизвестные символы.
- Корректные описания «Молока» и сторонних Docker-модулей.
- Формулировка о резервной копии больше не создаёт впечатление, что у generic Docker автоматически резервируется база.

**Следующие доработки**

1. **Состояние каждого модуля на его карточке.** Последняя успешная проверка, HTTP/health, контейнер, установленная версия и доступность новой — с датой замера.
2. **План перед обновлением.** Что изменится, какая резервная копия реально будет создана, какие сервисы перезапустятся. Использовать существующие данные обновлений, не дублировать их новым меню.
3. **Ссылки на сайт и настройки рядом.** Не искать домен в форме окружения; показывать отдельную безопасную ссылку без секретов.
4. **Журнал конкретного модуля по умолчанию.** Из проблемной карточки сразу открывать нужный журнал, а не общий список серверных событий.
5. **Сводка резервирования.** Когда реально сохранены данные, где копия, как проверить восстановление; код и база обозначены отдельно.
6. **Более понятное добавление модуля.** Шаблоны полей для известных проектов, предварительная проверка путей и сервисов без запуска обновления.

## «Молоко»

**Исправлено**

- Крупная декоративная бутылка уступила место кнопкам «Напомнить сейчас» и «Заменить» у ближайшего дежурного.
- В обзоре видно, сколько людей подключены и сколько ещё ждут подключения.
- Меню и пиктограммы совпадают по сетке и толщине; на телефоне меню находится снизу.
- Статус паузы визуально отличается от включённых отправок.

**Следующие доработки**

1. **Мастер первого запуска.** Бот → участники → первая дата → тестовая отправка → включение. Переход к незавершённому шагу прямо из обзора.
2. **Отпуск, исключённые даты и праздники.** Пропуск человека или дня без ручной перестройки всей очереди.
3. **Подтверждение «Выполнено» в боте.** Отдельно от факта отправки сообщения. Повторное напоминание только тем, кто ещё не подтвердил.
4. **Запрос замены от участника.** Согласование организатором, прежде чем меняется дежурный; без доступа участника к админ-панели.
5. **Календарь на месяц с переносом даты.** Сравнить первоначальное назначение и текущую замену, видеть уже отправленные уточнения.
6. **Сводка доставки.** Неподключён, заблокировал бота, Telegram временно недоступен и сообщение успешно доставлено — разные состояния и действия.

## «Штрих»

**Исправлено**

- Контурные иконки категорий и инструментов.
- «Назад» в инструментах теперь называется «Отменить штрих», а основное действие — «Оценить рисунок».
- На телефоне инструменты собраны в сетку, оценка доступна крупной кнопкой под холстом.
- Цвета получили понятные подписи для вспомогательных технологий; при открытии холста страница возвращается к заданию.
- Шапка и кнопки не должны растягивать всю страницу на узком экране.

**Следующие доработки**

1. **Короткое обучение у первого холста.** Цвет, толщина, отмена и оценка в четырёх понятных шагах.
2. **Сохранение незавершённого рисунка на устройстве.** Восстановление после перезагрузки, с явной кнопкой начать заново.
3. **Автоматическое обновление статуса оценки.** Состояния отправки/обработки/готовности с ограниченным повтором вместо инструкции обновить страницу.
4. **Режим организатора.** Понятно показывать доступность ИИ, лимит оценок и последние ошибки, не показывая ключ.
5. **Сочетания клавиш для инструментов.** После понятных подписей цветов добавить доступную справку: отмена штриха, смена кисти и отправка рисунка.
6. **История с изображением рисунка.** Сравнение с распознанным ответом и подписью задания, если хранение изображений разрешено настройками проекта.

## Vano Remote

У серверного relay нет пользовательской веб-панели. Основной интерфейс — Windows и Android.
Изменение CSS других модулей его не обновит; APK/EXE требуют отдельной сборки и проверки.

**Проблемы по исходникам**

- На Android в строках одновременно размещены 3–4 равноправные кнопки: первичная привязка, вход, отключение и вспомогательные действия конкурируют.
- Рядом с обычным управлением находятся операции удаления/отзыва привязки.
- В Windows окно фиксированного стартового размера и длинные ряды кнопок зависят от масштаба интерфейса.
- Подключение, биометрия, передача экрана и доступ к управлению имеют разные причины отказа, но представлены компактным статусом.

**Следующие доработки**

1. **Два основных режима: «Подключение» и «Управление».** До подключения показывать только инструкцию, код/QR и вход; затем — экран и управление.
2. **Отдельные индикаторы разрешений.** Связь, отпечаток, трансляция, управление; у каждой проблемы — собственная кнопка действия.
3. **Нижняя панель управления Android.** Крупные Enter/Backspace/правый клик; редкие команды убрать в раскрывающийся список.
4. **Привязки и отзыв доступа в настройках.** Разнести разрушительные и частые действия, сохранить существующие подтверждения и биометрию.
5. **Адаптивное окно Windows.** Минимальная ширина, растяжение экрана, перенос рядов и корректность при 125/150/200% масштабе.
6. **Экран устройства и режима соединения.** Видно, куда подключаемся, какой транспорт используется и какое управление разрешено.

## Правила нового общего рейтинга Pulse

- Вход в таблицу нужен; черновые данные не публикуются автоматически задним числом.
- Для ручных/игровых ведомостей есть действие «Опубликовать результат».
- Явная публикация результатов теста по ссылке организатором (администратором/модератором) также закрепляет доступную ведомость. Участник-автор не может сам добавлять результаты в общий рейтинг.
- Закрепляются название, дата, максимум и баллы. Автоматическая синхронизация последующих ответов снимок не меняет.
- Для пересчёта по изменённой ведомости используется «Обновить публикацию».
- «Открепить» убирает тест из рейтинга, сохраняя ведомость. Закреплённую ведомость нельзя удалить до открепления.
- Общий процент: среднее арифметическое процентов всех опубликованных тестов. Процент каждого теста = закреплённые баллы / его максимум × 100. Каждый тест имеет одинаковый вес.
- Пропуск — «—» в ячейке и 0% в общем итоге. Числовой ноль остаётся самостоятельным результатом.
- Сортировка — по проценту вниз; равные проценты (точность отображения 2 знака) дают одинаковое место: 1, 1, 3.
- CSV содержит те же места и баллы, что и таблица; поиск не перенумеровывает места.

## Проверка выпуска

- Pulse: реальный PHP/SQLite API, публикация/перепубликация/открепление, права, замороженные баллы, проценты, равные места и пропуски — автоматические проверки пройдены.
- GitDeck: 36 серверных тестов и UI-проверки конфигурации пройдены.
- «Молоко»: 23 теста пройдены, включая доставку общих CSS/JS до входа.
- PWA: ресурсы и границы установки четырёх PHP-модулей проверены; проверка восстановления Telegram-сессии пройдена.
- В браузере проверены настольный и мобильный Pulse/Marathon, мобильные «Молоко», GitDeck, «Штрих» и реальная оболочка Chrono на тестовом содержимом. Рабочие токены и отправка сообщений не использовались.
- Chrono: полные игровые сценарии с реальной базой в этой среде не проверены. Vano Remote: нативные сборки не менялись и не запускались; предложения требуют отдельного выпуска клиентов.

## Обновление сервера

Этот выпуск передаётся через GitHub. Для применения обновите GitDeck и затем соответствующие модули из панели. Удалённое развёртывание и реальные аккаунты в этой сессии не проверены: SSH-доступ отсутствует.
Существующие ведомости Pulse остаются черновыми для общего рейтинга до явного действия «Опубликовать результат».
