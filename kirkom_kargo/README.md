# KirkomKargo

Функциональное демо: посылки, расчёт веса, статусы, оплата, CSV и текст WhatsApp.
Данные сохраняются только в localStorage браузера. Pinduoduo и WhatsApp API не подключены.
Не используйте прототип как общую базу клиентов или бухгалтерский учёт.

## Установка через GitDeck

1. Обновите сам GitDeck из Git (ветка main).
2. После перезапуска появится карточка «KirkomKargo · управление карго».
3. Нажмите «Обновить из Git». Первая установка создаст /opt/kirkom-kargo,
   соберёт контейнер, проверит health и добавит маршрут kirkom.vano.sbena.net
   в существующий HTTPS-прокси Marathon/Pulse.
4. Последующие обновления заменяют только web и ops. Compose и настройки сервера сохраняются.

Если HTTPS не подключился, задание покажет ошибку. Повторное обновление повторяет
установку при отсутствии overlay. При существующем overlay и ошибке прокси:
`sudo python3 /opt/kirkom-kargo/ops/connect_https.py kirkom.vano.sbena.net`.
Конфликтующий маршрут не заменяется. Другие сайты не пересоздаются.

Локально: `python3 -m http.server 8080 --directory web`.
Контейнер: `docker compose up -d --build --wait`.
Доступ без HTTPS: SSH-туннель к 127.0.0.1:8185.

Для рабочего продукта нужны серверная БД, роли, журнал, резервирование,
фиксирование тарифа накладной, согласованный учёт округления и подключение API.
