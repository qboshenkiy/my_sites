# Kirkom Cargo

Управление посылками и клиентами, статусы доставки, расчёт по весу,
частичные оплаты, финансовый журнал, уведомления WhatsApp и экспорт.
Node.js 24, SQLite в постоянном томе, без npm-зависимостей.

## GitDeck

Обновите GitDeck, затем карточку Kirkom Cargo через «Обновить из Git».
Первая установка или переход со старой версии создаёт контейнер приложения,
постоянный том и HTTPS-маршрут kirkom.vano.sbena.net.
Первоначальный пароль совпадает с паролем GitDeck на момент установки.
Пароли хранятся как scrypt-хеши. Серверные сессии действуют 12 часов.
Старые стандартные Nginx Dockerfile/Compose копируются в .before-cargo-server
при переходе на серверную версию. Пользовательские конфигурации не мигрируются.
Тариф требуется подтвердить в настройках перед первой приёмкой.
Старые данные localStorage не импортируются автоматически.

## Данные

Тариф и курс фиксируются в накладной; новые настройки не меняют прежние суммы.
Вес нельзя изменить после оплаты. Выдача доступна после полного расчёта.
Изменения используют версию состояния, конфликтующие записи отклоняются.
История операций сохраняется на сервере. «Выгрузить копию» экспортирует JSON.
Перед обновлением сделайте резервную копию постоянного Docker-тома cargo-data;
общий Docker-модуль GitDeck автоматически сохраняет только исходный код.
Восстановление выполняется администратором при остановленном контейнере.

## Подключения

WhatsApp: готовится текст, открывается личный чат по номеру; сообщение
отправляет оператор. Массовые и автоматические рассылки пока не реализованы.
Pinduoduo: прямой API не подключён, трек-номер вводит оператор.
В интерфейсе нет фиктивных статусов интеграций и отправки.
Доступ единой команды, один пароль оператора; персональные роли и аккаунты
пока не реализованы. Внешний доступ ограничьте сотрудниками через HTTPS.
