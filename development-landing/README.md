# Разработка на заказ

Лендинг и примеры сайтов на https://job.vano.sbena.net. Web-процесс сохраняет заявки в SQLite, отдельный процесс Telegram принимает сообщения и доставляет заявки владельцу. GitDeck обновляет каталоги app и dist, данные находятся в storage.

В /admin задайте международный номер WhatsApp, личный Telegram (@username или номер с +) и токен отдельного бота из BotFather. Для связи по номеру в Telegram должны это позволять настройки приватности. После сохранения токена нажмите «Получить код подключения» и отправьте полученную команду в личный чат с ботом. Новые заявки с сайта и из бота сохраняются в админке и доставляются в привязанный чат. Заявки, ожидающие подключения, остаются в очереди.

Для первого входа администратор сервера создаёт файл storage/bootstrap с временным паролем. Приложение сохраняет только хеш и удаляет файл при запуске. После первого входа смените пароль в админке.

Для локального запуска используйте отдельный каталог данных и укажите JOB_ORIGIN=http://127.0.0.1:8080. Команда: python3 app/server.py.
