# Игры из книг и импорт JSON

Откройте «Мои игры» → «Бытие: 50 глав» или «Импорт JSON». Вставьте JSON либо выберите файл,
нажмите «Проверить JSON», отметьте нужные карточки и подтвердите импорт. До подтверждения база не меняется.
Новая игра создаётся черновиком; администратор может опубликовать её через управление играми.

Для добавления следующей книги откройте существующую игру и нажмите «Добавить из JSON / другой книги».
По умолчанию новые события располагаются после имеющихся, с сохранением относительного порядка из JSON.
Чтобы вставить события между существующими, снимите отметку «Добавить события после имеющихся» и задайте точные значения `sort_order`.
Название и описание существующей игры при добавлении карточек сохраняются.

В редакторе:

- Создавайте и удаляйте карточки вручную, меняйте текст, порядок, изображения, категорию и сложность.
- Переключателем «В игре» можно исключить событие без удаления и позже вернуть его.
- Поиск, фильтр категорий и фильтр включённых/выключенных карточек помогают выбрать состав.
- «Включить показанные» / «Выключить показанные» применяются ко всем видимым после фильтрации карточкам.
- В поле «Категория» задайте книгу или раздел, например `Бытие · Авраам` или `Исход`.
- «Скачать JSON» сохраняет карточки для переноса в другую игру. Картинки экспортом не переносятся.

Новые партии используют только включённые карточки. Начавшаяся партия уже хранит снимок колоды и от изменения редактора не меняется.
Для публикации нужны минимум две заполненные включённые карточки. Для обычной раздачи — одна стартовая карточка плюс число игроков × число карт в руке.

## Формат

```json
{
  "title": "Моя хронология",
  "description": "События в порядке повествования",
  "book": "Бытие",
  "cards": [
    {
      "title": "Сотворение мира",
      "short_description": "Бог создаёт мир и человека.",
      "sort_order": 1,
      "reference": "Бытие 1:1–31",
      "category": "Бытие · Начало мира",
      "difficulty": "NORMAL",
      "is_enabled": true
    },
    {
      "title": "Призвание Аврама",
      "sort_order": 12,
      "reference": "Бытие 12:1–9"
    }
  ]
}
```

Обязательны `title` игры, массив `cards`, `title` и `sort_order` каждой карточки.
Чем меньше `sort_order`, тем раньше событие. Это число (можно передать строкой) с максимум 14 цифрами перед точкой и 6 после.
Допустимы отрицательные числа и дроби, например `12.5` для события между 12 и 13.
`reference` или `revealed_value` показывается после ответа; не помещайте подсказку порядка в открытое описание карточки.
Если `category` не указана, используется `book`. Сложность: `EASY`, `NORMAL`, `HARD`, `EXPERT`.
Поле `is_enabled` — логическое `true` или `false`; по умолчанию `true`.
Поддерживаются также псевдонимы `events` вместо `cards`, `event` вместо `title`, `order` вместо `sort_order`, `description` вместо `short_description` у карточки.

Ограничения: 2 МБ и 1000 карточек за импорт. Текстовое поле не обрезает вставку.
Некорректная карточка отклоняет весь импорт. Запись выполняется одной транзакцией.
Карточки добавляются, а не заменяют существующие; повторный импорт того же файла добавит копии.
Роли, владелец, статус публикации, внутренние идентификаторы и произвольные URL картинок из JSON не импортируются.
Импорт и экспорт доступны владельцу игры и администратору, с проверкой CSRF для изменений.

## Бытие: 50 глав

Готовый файл: `app/Data/genesis-50.json`; скачать через сайт можно по кнопке «Скачать пример JSON» в импорте.
В нём 50 карточек — по одной на главу, со ссылками на стихи Синодального перевода.
Используется **порядок повествования**, без предположительных дат до нашей эры.
Родословия и параллельные сюжеты могут описывать более ранние события: например, раздел об Исаве в главе 36.

Текст для сверки: [Бытие, Синодальный перевод](https://bible.by/syn/1/1/),
[потомки Исава](https://bible.by/syn/1/36/), [завершение книги](https://bible.by/syn/1/50/).

## Обновление и проверки

В GitDeck обновите Chrono Logos из `my_sites`, папка `chrono_logos`. Отдельное обновление GitDeck для импорта не требуется.
Миграция автоматически добавит признак включения, существующие карточки будут включены.
Сам пример не создаёт чужую игру и не публикует её автоматически: нужные карточки импортируются после подтверждения владельцем.

`php tests/timeline_import.php` проверяет формат и покрытие 50 глав.
`python tests/deploy_smoke.py` проверяет миграции, HTTP-импорт, права, экспорт и снимок выбранной колоды на временной PostgreSQL.
Для браузерного теста дополнительно установите Playwright с Chromium, включите `TIMELINE_UI=1` и запустите тот же smoke test.
