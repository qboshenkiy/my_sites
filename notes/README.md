# Заметки — место для мыслей

Отдельное приватное приложение для одного владельца: заметки с названием и текстом, папки, поиск по содержимому (включая регистр кириллицы), закрепление, корзина и восстановление. Веб и Ubuntu используют одну SQLite-базу на сервере. Для чтения и сохранения нужен интернет. Вложения, публичные ссылки и совместные аккаунты в эту версию не входят.

## GitDeck

1. Обновите GitDeck до 1.13.0: карточка самой панели → «Обновить панель».
2. На автоматически добавленной карточке **«Заметки · место для мыслей»** нажмите **«Настроить Заметки»**.
3. После успешного задания откройте `https://notes.vano.sbena.net/`. DNS должен указывать на сервер; существующая wildcard-запись подходит. При первом входе используйте пароль GitDeck.

Установщик использует существующий HTTPS-прокси Marathon/Pulse и создаёт отдельный маршрут. Проверка Caddy предшествует применению, при ошибке файлы восстанавливаются. Нужны существующий GitDeck, Docker/Compose и HTTPS-прокси. Модуль устанавливается в `/opt/notes`, порт 8170 доступен только на loopback. Пароль копируется как scrypt-хеш по stdin; в коде, аргументах команд и журнале открытого пароля нет. Повторная установка сохраняет действующий пароль, `.env`, Docker-том и Compose.

Обновление приложения: карточка **Заметки → Обновить из Git**. Источники в `notes/`, код — `src`, `web`, `requirements.txt`. Данные и ключ сессии в отдельном томе `notes-data`, вне репозитория. Регистрации и публичного чтения заметок нет.

## Автосохранение и защита правок

После ввода — автосохранение с задержкой 600 мс; Ctrl+S сохраняет сразу. Статус внизу редактора показывает результат. При отсутствии сети изменения остаются в открытом редакторе, доступна повторная попытка. Перед переключением заметки, выходом и перемещением в корзину приложение ждёт сохранения. При закрытии с несохранённым текстом веб и Ubuntu предупреждают пользователя. Не закрывайте редактор до сохранения.

У каждой заметки номер ревизии. Устаревшая запись с другого устройства отклоняется с HTTP 409, не заменяя серверный текст. Редактор предлагает скачать свой несохранённый черновик или открыть актуальную серверную версию. Старые 20 сохранённых состояний на заметку сохраняются в базе для восстановления администратором. Не обещается сохранность черновика после аварийного завершения ОС/процесса: офлайн-хранилища нет.

Корзина не очищается автоматически, окончательного удаления через интерфейс нет. При удалении папки её заметки переходят в «Все заметки». JSON-экспорт включает заметки, корзину и папки, не включает пароли/сессии. Отдельную заметку можно скачать TXT. Для полного резервного копирования сохраняйте Docker-том при остановленном web или через SQLite backup API.

## Ubuntu

`python3 notes/native/linux/install.py` из корня репозитория устанавливает приложение текущему пользователю, добавляет ярлык «Заметки» и иконку в меню. Требуются `python3-gi`, `gir1.2-gtk-3.0`, `gir1.2-webkit2-4.1`. Данные WebKit и cookie хранятся отдельно в `~/.local/share/vano-notes`, каталог с правами 0700.

Системный установщик: `notes/web/notes-desktop_1.0.0_all.deb` (также ссылка в приложении). Собрать заново: `python3 notes/native/linux/build.py`. Установка через Ubuntu App Center или `sudo apt install ./notes-desktop_1.0.0_all.deb`. Пакет добавляет launcher `vano-notes`, системную иконку и ярлык. Приложение открывает только свой HTTPS-домен; внешние HTTPS-ссылки — в обычном браузере. Изменения веб-интерфейса доступны без пересборки оболочки.

## Проверки

`python3 -m venv /tmp/notes-venv && /tmp/notes-venv/bin/pip install -r notes/requirements.txt`

`/tmp/notes-venv/bin/python notes/tests/test_notes.py` — временная база, авторизация, CSRF, сохранение, поиск, конфликт версий, корзина, папки, экспорт и файлы приложения.

`node notes/tests/autosave.cjs` — последовательное сохранение во время набора, изменение закрепления и восстановление после конфликта.

`python3 -m unittest discover -s deploy-panel -p tests_notes.py` — регистрация и безопасная повторная установка в GitDeck.
