# Заметки — место для мыслей

Отдельное приватное приложение для одного владельца: заметки с названием и текстом, папки, поиск по содержимому (включая регистр кириллицы), закрепление, корзина и восстановление. Веб и Ubuntu используют одну SQLite-базу на сервере. После первого входа с интернетом заметки доступны офлайн на этом устройстве. Вложения, публичные ссылки и совместные аккаунты в эту версию не входят.

## GitDeck

1. Обновите GitDeck до 1.14.0: карточка самой панели → «Обновить панель».
2. На автоматически добавленной карточке **«Заметки · место для мыслей»** нажмите **«Настроить Заметки»**.
3. После успешного задания откройте `https://notes.vano.sbena.net/`. DNS должен указывать на сервер; существующая wildcard-запись подходит. При первом входе используйте пароль GitDeck.

Установщик использует существующий HTTPS-прокси Marathon/Pulse и создаёт отдельный маршрут. Проверка Caddy предшествует применению, при ошибке файлы восстанавливаются. Нужны существующий GitDeck, Docker/Compose и HTTPS-прокси. Модуль устанавливается в `/opt/notes`, порт 8170 доступен только на loopback. Пароль копируется как scrypt-хеш по stdin; в коде, аргументах команд и журнале открытого пароля нет. Повторная установка сохраняет действующий пароль, `.env`, Docker-том и Compose.

Обновление приложения: карточка **Заметки → Обновить из Git**. Источники в `notes/`, код — `src`, `web`, `requirements.txt`. Данные и ключ сессии в отдельном томе `notes-data`, вне репозитория. Регистрации и публичного чтения заметок нет.

## Автосохранение, офлайн и синхронизация

После ввода — сохранение на устройстве с задержкой 600 мс; Ctrl+S сохраняет сразу. В IndexedDB хранится локальная копия всех заметок и очередь изменений. После первого входа Service Worker кеширует только оболочку приложения и статические файлы, без API-ответов и заметок. Это позволяет повторно запустить веб и Ubuntu без сети. Личные тексты хранятся отдельно в IndexedDB профиля браузера/WebKit.

Можно офлайн создавать и редактировать заметки, закреплять их, перемещать в уже загруженные папки, пользоваться поиском, корзиной и экспортом. Создание, переименование и удаление самих папок требуют связи. Индикатор сверху отличает сохранение на устройстве от синхронизации с сервером. Очередь переживает закрытие и повторный запуск; выход из аккаунта очищает локальную копию только после отправки правок и успешного выхода на сервере.

При восстановлении связи синхронизация запускается автоматически в открытом приложении (также проверяется раз в 15 секунд), либо при следующем запуске. У каждого изменения случайный идентификатор; повторная отправка после потери ответа не создаёт дубликаты. Номер ревизии проверяется на сервере. Если другая версия уже изменилась, офлайн-правка сохраняется отдельной заметкой с пометкой «конфликт»; исходная заметка другого устройства остаётся целой. После истечения сессии приложение просит снова войти для отправки очереди.

Перед первым офлайн-запуском нужно один раз открыть приложение с интернетом и дождаться индикатора готовности. Локальные данные зависят от диска/профиля браузера: очистка данных сайта или удаление профиля удаляет и несинхронизированную очередь. Не очищайте их до синхронизации. До сохранения в локальную базу закрытие окна предупреждает о несохранённом вводе. Старые 20 состояний на заметку также хранятся в серверной базе для восстановления администратором.

Корзина не очищается автоматически, окончательного удаления через интерфейс нет. При удалении папки её заметки переходят в «Все заметки». JSON-экспорт включает заметки, корзину и папки, не включает пароли/сессии. Отдельную заметку можно скачать TXT. Для полного резервного копирования сохраняйте Docker-том при остановленном web или через SQLite backup API.

## Ubuntu

`python3 notes/native/linux/install.py` из корня репозитория устанавливает приложение текущему пользователю, добавляет ярлык «Заметки» и иконку в меню. Требуются `python3-gi`, `gir1.2-gtk-3.0`, `gir1.2-webkit2-4.1`. Данные WebKit и cookie хранятся отдельно в `~/.local/share/vano-notes`, каталог с правами 0700.

Системный установщик: `notes/web/notes-desktop_1.1.0_all.deb` (также ссылка в приложении). Собрать заново: `python3 notes/native/linux/build.py`. Установка через Ubuntu App Center или `sudo apt install ./notes-desktop_1.1.0_all.deb`. Пакет добавляет launcher `vano-notes`, системную иконку и ярлык. Приложение открывает только свой HTTPS-домен; внешние HTTPS-ссылки — в обычном браузере. Изменения веб-интерфейса доступны без пересборки оболочки.

## Проверки

`python3 -m venv /tmp/notes-venv && /tmp/notes-venv/bin/pip install -r notes/requirements.txt`

`/tmp/notes-venv/bin/python notes/tests/test_notes.py` — временная база, авторизация, CSRF, сохранение, поиск, конфликт версий, корзина, папки, экспорт и файлы приложения.

`node notes/tests/autosave.cjs` — последовательное сохранение во время набора, изменение закрепления и восстановление после конфликта.

`python3 -m unittest discover -s deploy-panel -p tests_notes.py` — регистрация и безопасная повторная установка в GitDeck.

Офлайн-очередь: `npm install --prefix /tmp/notes-offline-test fake-indexeddb`, затем `FAKE_INDEXEDDB_MODULE=/tmp/notes-offline-test/node_modules/fake-indexeddb node notes/tests/offline.cjs`. Проверяются перезапуск, накопление изменений без сети, синхронизация, потерянные ответы, конфликтные копии и безопасный выход.

## Android и Telegram

Android: `notes/native/android`, package ID `net.sbena.vano.notes`. Workflow **Build Notes Android** проверяет и собирает подписанный release APK в `notes-latest/notes-android.apk`, используя существующий постоянный ключ репозитория. Оболочка учитывает системные панели/клавиатуру, сохраняет сессию и локальную офлайн-базу WebView. Экспорт TXT/JSON открывает системный выбор файла; произвольного доступа к файлам приложение не получает.

Для Telegram нужен отдельный бот. В GitDeck → Заметки → Настройки сайта сохраните `TELEGRAM_BOT_TOKEN`, по желанию `TELEGRAM_BOT_USERNAME`. `web` и `bot` используют один том с заметками. Старую установку дополните кнопкой «Настроить Заметки»: она добавит управляемое Compose-наложение, не заменяя Compose и базу. После обновления панели 1.14.0 оба сервиса доступны в карточке.

В приложении → Настройки → Telegram получите одноразовый код и отправьте `/start КОД` своему боту в личном чате. Код действует 10 минут; только привязанный Telegram имеет доступ. Кнопки: новая заметка, мои заметки, поиск, закреплённые и Mini App. Обычный текст сохраняется как заметка, первая строка — название. В заметку можно дописать текст, закрепить её или переместить в корзину; удаление остаётся восстановимым. Повторные Telegram updates не создают дубликаты.

Mini App проверяет HMAC-SHA256 `initData`, срок (до часа) и совпадение Telegram ID с привязанным аккаунтом. Неизвестный Telegram не получает доступ. Отключение Telegram отзывает его серверные сессии. Для автоматического входа запускайте приложение через inline-кнопку/меню бота. Сам бот и первый запуск Mini App требуют связи с Telegram. Офлайн-редактор доступен в вебе, Ubuntu и Android после первой онлайн-загрузки; отправка очереди идёт при открытом приложении либо следующем запуске.
