# Штрих — отдельная игра с рисунками

Игрок выбирает категорию, получает случайное задание, рисует пальцем или мышью.
ИИ сначала независимо угадывает рисунок, затем сравнивает с заданием и даёт 1–5
звёзд с советом. Есть кисти, цвета, ластик, отмена штриха, подтверждение отправки,
личная история последних 30 результатов. Администратор создаёт, редактирует,
убирает категории и импортирует JSON. Готовые категории: животные, природа,
транспорт и события Бытия. Мультиплеер и Telegram в эту версию не входят.

## Установка через GitDeck

Обновите панель до 1.4.0. Добавьте модуль **Штрих — рисунки и ИИ**:
`https://github.com/qboshenkiy/my_sites.git`, ветка `main`, папка `sketch_game`,
каталог `/opt/sketch-game`. Нажмите обновление из Git: первая установка создаёт
Docker Compose, постоянный том и случайные пароли автоматически.

В настройках сайта задайте:

- `APP_URL=https://draw.vano.sbena.net/` и `HTTPS_PROXY_PROJECT=marathon`
  (выберите фактический HTTPS-модуль из списка). DNS должен указывать на сервер.
- Свой `ADMIN_PASSWORD` — минимум 12 символов.
- Свой `GAME_ACCESS_CODE` — минимум 8 символов. Этот код передаётся участникам.
- `OPENAI_API_KEY` — серверный ключ OpenAI с доступом к выбранной модели и балансом.
- `OPENAI_MODEL` — по умолчанию `gpt-4.1-mini`; `AI_DAILY_LIMIT` — число попыток
  оценки на весь сайт в день (UTC), по умолчанию 100.

Сохраните настройки. Отдельно покупать сертификат не нужно: используется HTTPS-прокси
марафона. Без ключа доступен холст для тренировки, выдуманные оценки не показываются.
Реальный API оплачивается отдельно; одна оценка использует два запроса с изображением.
Рисунок отправляется OpenAI только после подтверждения игроком. В браузер ключ не попадает.

## Вручную

Скопируйте `.env.example` в `.env`, задайте пароли и ключ, скопируйте
`ops/compose.yaml` в `compose.yaml`, затем `docker compose up -d --build --wait`.
Настройте HTTPS через обратный прокси либо откройте тестовый HTTP-порт 8084.
Не удаляйте том `data`: в нём SQLite с историей, категориями и сессиями.
GitDeck сохраняет SQLite перед обновлением и восстанавливает его при неудаче.

Пример импорта:

```json
{"categories":[{"title":"Бытие","words":["Ноев ковчег","Вавилонская башня"]}]}
```

Протокол ИИ: [OpenAI: изображения](https://developers.openai.com/api/docs/guides/images-vision),
[Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs).
Тесты используют имитацию ответов ИИ; реальный платный вызов без пользовательского ключа не выполнялся.
